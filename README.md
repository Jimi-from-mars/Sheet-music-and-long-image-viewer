# Sheet Music and Long Image Viewer （乐谱/长图浏览器）

**Version: 1.2**

## 简介
**Sheet Music and Long Image Viewer（乐谱/长图浏览器）** 是一款专为浏览长图片（如乐谱、漫画、海报等）设计的工具。  
它能够将垂直方向超长的图像按设定的高度切割成多页并排展示，适用于演奏、超宽屏浏览等场景，提升查看长图的体验。

## 特性
- 支持超长图片（如钢琴谱、长漫画、学习资料）分段并排浏览
- 自定义切割比例
- 支持快速缩放查看
- 支持搜索当前文件夹及其子文件夹中的图片
- 记忆搜索结果窗口的大小和位置
- 按需生成可见页面，提升长图放大和滚动时的响应速度
- 明亮、专业的圆角界面与渐变画布背景
- 支持多种常见图片格式（JPG, PNG, BMP等）
- 适配超宽屏显示器

### 运行方式
- **方式一**：下载编译版（推荐，适合普通用户）
- **方式二**：克隆本仓库，在本地 Python 环境中运行源代码

### 搜索图片
- 在顶部搜索栏输入文件名关键词，点击“搜索”或按回车键，即可搜索当前打开文件夹中的图片。
- 勾选“搜索子文件夹”后，会同时搜索当前文件夹下的所有子文件夹。
- 搜索结果使用相对于当前文件夹的路径显示，单击任意结果即可加载图片。
- 搜索结果窗口可自由移动和调整大小，程序会记住窗口上次关闭时的大小和位置；桌面分辨率改变导致原位置越界时，会自动回到默认位置。
